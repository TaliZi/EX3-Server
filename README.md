*In this project we created 3 screens: 
1. Login screen
2. Registration screen
3. Feed screen.*


## Run:
### In the server directory, you should run the commands below:

npm cache clean --force

npm install

npm install jwt-decode

npm start

### Then open in browser

http://localhost:3000
 
### Make sure to have mongoDB installed on your computer and have a DB in the address of mongodb://localhost:27017/myapp.
